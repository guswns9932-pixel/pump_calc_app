# Pump 판가 계산기 (Python 이식판)

원본 `대외비_Pump_판가_계산기_이력추가_ver4_0.xlsm` (판가계산기 / Sheet3 / Rawdata / 이력)을
Python(Tkinter)으로 이식한 데스크톱 앱입니다.

## 실행 방법

1. Python 3.9 이상이 설치되어 있어야 합니다. (Windows는 기본 설치 시 Tkinter 자동 포함)
2. 이 폴더(`pump_calc_app`) 전체를 그대로 옮겨서 실행하면 됩니다. (외부 라이브러리 설치 불필요)

```bash
python pump_calc_app.py
```

Windows에서는 `pump_calc_app.py`를 더블클릭해도 실행됩니다 (파이썬이 설치되어 있다면).

## 폴더 구성

```
pump_calc_app/
├── pump_calc_app.py    # 메인 프로그램 (이 파일만 실행하면 됨)
├── build_exe.py         # Windows용 .exe 빌드 스크립트 (선택사항)
├── README.md
├── tests/                # 자동 테스트 (pytest)
│   ├── conftest.py
│   └── test_pump_calc_app.py
└── data/
    ├── rawdata.csv          # 원본 Rawdata(PUMP 판가 DATA) 시트 (과거 실적 71건, 조회 전용)
    ├── history.csv          # 원본 이력 시트 (51건, 이후 등록 건 계속 누적)
    ├── settings.json        # 재료비/영업이익률/비율 등 마지막 입력값 저장 (앱 종료 후에도 유지)
    ├── history_edit_log.txt # 이력 등록/수정/삭제 로그 (시간 · No./장비 모델 · 변경 내용, 자동 누적)
    └── backups/              # 이력 저장 직전 자동 백업 (최근 20개, 오래된 것부터 자동 정리)
```

`data` 폴더는 프로그램과 함께 이동해야 기존 이력·Rawdata가 유지됩니다.

## 원본 대비 변경/유지 사항

| 항목 | 원본(Excel) | Python 이식판 |
|---|---|---|
| 계산 수식 | 재료비→노무비+경비→판관비→영업이익→적정판가 | **완전히 동일한 수식** 그대로 유지 |
| 노무비+경비 비율 (20%) | Sheet3 셀에 하드코딩, 수정하려면 수식 편집 필요 | 화면에서 즉시 직접 입력 가능 |
| 판관비 비율 (30%) | Sheet3 셀에 하드코딩 | 직접 입력 가능 |
| 영업이익률 | 판가계산기 시트에서 입력 | 동일하게 입력 |
| 화면 구성 | 판가계산기 / Sheet3 / Rawdata / 이력 (4개 시트) | **Sheet3를 판가계산기 우측 "원가 구조 계산" 패널로 통합**하고, Rawdata·이력은 상단 버튼을 눌러 **전체화면 새 창**으로 확인 (탭을 넘나들 필요 없음) |
| 이력등록 절차 | VBA 매크로가 순서대로 팝업 15개를 띄워 정보 수집 | 팝업 15개 대신 **한 화면 입력폼**에 모든 항목을 모아서 한 번에 입력 |
| 이력 No./일시/계산금액 자동기록 | 매크로가 자동 채움 | 동일 로직으로 자동 채움. 등록 즉시 이력 창이 열리며 새 항목이 자동 선택됨 |
| Rawdata 수정 | 엑셀 시트에서 직접 수정 가능 | **조회 전용으로 변경** (실수로 원본 데이터가 바뀌는 것을 방지) |
| 이력 셀 수정 | 아무 셀이나 자유 입력 | 셀 더블클릭으로 수정하되, **이력등록 시 목록에서 선택했던 항목**(제출여부/지역/고객구분/사업부/대공정/장비사)은 더블클릭 시 **동일한 선택 목록**이 나타나 오탈자 없이 수정 가능 |
| 금액 표시 | 서식 없는 숫자 | 재료비/계산금액/제출금액 등 금액 관련 열은 **1,234,567원 형태로 콤마 표기** |
| 영업이익률 표시 | 0.5 같은 소수 | **50.0% 형태로 표기** |
| 줄바꿈 데이터 | 셀 안에 줄바꿈이 섞여 표/정렬이 흐트러짐 | 이력 데이터에 줄바꿈이 있으면 **자동으로 공백으로 정리**되어 저장 |
| 검색 | 없음 | 이력 창에 **검색창**을 추가해 키워드로 즉시 필터링 |
| 열 너비 조절 | 열 하나를 조절하면 옆 열이 밀리거나 당겨짐 | 열마다 **독립적으로 너비 조절** (옆 열에 영향 없음, 넘치는 영역은 가로 스크롤) |
| 새로고침 | - | 새로고침 시 데이터와 함께 **열 너비도 기본값으로 초기화** |
| 디자인 | 엑셀 시트 그대로 | 카드형 레이아웃과 통일된 색상/폰트로 **더 정돈된 화면** |
| 저장 안전성 | 엑셀 자체 저장 방식에 의존 | 저장 시 **임시 파일에 먼저 쓴 뒤 교체**(원자적 저장)하고, **이력 저장 직전 자동 백업**(`data/backups/`, 최근 20개 보관)을 남겨 잘못된 저장으로 인한 데이터 손실을 예방 |
| 이력 삭제 | 셀 내용을 지우거나 행을 직접 삭제 | 이력 창에서 행 선택 후 **[선택 삭제]**로 삭제 (삭제 전 확인, 삭제 내용은 로그에 기록) |
| 엑셀 내보내기 | 원본 자체가 엑셀 | Rawdata/이력 창에서 **[엑셀로 내보내기]**로 현재 화면(검색/정렬 적용된 상태)을 `.xlsx`로 저장 (추가 라이브러리 설치 없이 동작) |
| 이력 조회 순서 | 등록 순서 그대로 | **No. 내림차순**(최신 등록이 위)으로 표시 |

## 계산 로직 (변경되지 않음)

```
재료비(원가)      = 사용자 입력값
노무비+경비       = 재료비 × 노무비+경비 비율   (기본 20%, 직접 수정 가능)
판관비            = (재료비+노무비+경비) × 판관비 비율   (기본 30%, 직접 수정 가능)
영업이익          = (재료비+노무비+경비+판관비) × 영업이익률   (판가계산기 화면에서 입력)
적정 판가         = 재료비+노무비+경비+판관비+영업이익
```

## 테스트

계산 로직/파싱/서식/CSV 저장·백업/로그/엑셀 내보내기 등 핵심 로직에 대한 자동 테스트가
`tests/` 폴더에 있습니다 (화면이 없는 환경에서도 실행되도록 Tk 창을 직접 띄우는 GUI
테스트는 포함하지 않았습니다).

```bash
pip install pytest
pytest tests/
```

원본 Sheet3 예시값(재료비 1,000,000 / 비율 20%·30%·50%)으로 계산 시
`적정 판가 = 2,340,000`이 나오는 것도 이 테스트에 포함되어 있습니다 (원본 파일의 샘플 값과 100% 일치).

테스트는 실제 `data/` 폴더를 건드리지 않도록 임시 폴더에서 동작합니다.

## Windows 실행 파일(.exe) 만들기

파이썬이 설치되어 있지 않은 PC에도 배포하려면 실행 파일로 패키징할 수 있습니다.
(PyInstaller는 실행 중인 OS용 파일만 만들 수 있으므로, **Windows PC에서** 아래를 실행해야
`.exe`가 나옵니다.)

```bash
pip install pyinstaller

# 실행 파일(=작업관리자에 표시되는 프로세스) 이름을 직접 지정
python build_exe.py --name 우리팀_판가계산기

# 이름을 지정하지 않으면 실행 중에 물어봅니다 (엔터만 누르면 기본값 PumpPriceCalculator 사용)
python build_exe.py
```

완료되면 `dist\<지정한 이름>.exe`가 생성됩니다. 이 실행 파일을 `data` 폴더와
같은 위치에 두고 실행하면 됩니다 (`data` 폴더는 exe 안에 포함하지 않으므로, 기존에
쓰던 `data` 폴더를 그대로 exe 옆에 복사해 오면 이력이 유지됩니다).
