# Pump 판가 계산기 (Python 이식판)

원본 `대외비_Pump_판가_계산기_이력추가_ver4_0.xlsm` (판가계산기 / Sheet3 / Rawdata / 이력)을
Python(Tkinter)으로 이식한 데스크톱 앱입니다.

## 실행 방법

1. Python 3.9 이상이 설치되어 있어야 합니다. (Windows는 기본 설치 시 Tkinter 자동 포함)
2. 이 폴더(`pump_calc_app`) 전체를 그대로 옮겨서 실행하면 됩니다. (외부 라이브러리 설치 불필요)

```bash
python app.py
```

Windows에서는 `app.py`를 더블클릭해도 실행됩니다 (파이썬이 설치되어 있다면).

## 폴더 구성

```
pump_calc_app/
├── app.py              # 메인 프로그램 (이 파일만 실행하면 됨)
├── README.md
└── data/
    ├── rawdata.csv      # 원본 Rawdata 시트 (과거 실적 71건)
    ├── history.csv      # 원본 이력 시트 (51건, 이후 등록 건 계속 누적)
    └── settings.json    # 재료비/영업이익률/비율 등 마지막 입력값 저장 (앱 종료 후에도 유지)
```

`data` 폴더는 프로그램과 함께 이동해야 기존 이력·Rawdata가 유지됩니다.

## 원본 대비 변경/유지 사항

| 항목 | 원본(Excel) | Python 이식판 |
|---|---|---|
| 계산 수식 | 재료비→노무비+경비→판관비→영업이익→적정판가 | **완전히 동일한 수식** 그대로 유지 |
| 노무비+경비 비율 (20%) | Sheet3 셀에 하드코딩, 수정하려면 수식 편집 필요 | **판가계산기 탭에서 즉시 직접 입력** 가능 (요청사항 반영) |
| 판관비 비율 (30%) | Sheet3 셀에 하드코딩 | **직접 입력** 가능 (요청사항 반영) |
| 영업이익률 | 판가계산기 시트에서 입력 | 동일하게 판가계산기 탭에서 입력 |
| 이력등록 절차 | VBA 매크로가 순서대로 팝업 15개를 띄워 정보 수집 | **동일한 순서·동일한 선택지**로 팝업(마법사) 진행 |
| 이력 No./일시/계산금액 자동기록 | 매크로가 자동 채움 | 동일 로직으로 자동 채움 |
| 이력/Rawdata 셀 수정 | 엑셀 시트에서 아무 셀이나 직접 수정 가능 | 두 탭 모두 **셀 더블클릭으로 직접 수정** 가능 (엑셀과 동일한 사용성) |
| 시트 구성 | 판가계산기 / Sheet3 / Rawdata / 이력 | **탭 이름까지 동일**하게 구성 |

## 계산 로직 (변경되지 않음)

```
재료비(원가)      = 사용자 입력값
노무비+경비       = 재료비 × 노무비+경비 비율   (기본 20%, 직접 수정 가능)
판관비            = (재료비+노무비+경비) × 판관비 비율   (기본 30%, 직접 수정 가능)
영업이익          = (재료비+노무비+경비+판관비) × 영업이익률   (판가계산기 탭에서 입력)
적정 판가         = 재료비+노무비+경비+판관비+영업이익
```

## 테스트

원본 Sheet3 예시값(재료비 1,000,000 / 비율 20%·30%·50%)으로 계산 시
`적정 판가 = 2,340,000`이 나오는 것을 자동 테스트로 검증했습니다. (원본 파일의 샘플 값과 100% 일치)
